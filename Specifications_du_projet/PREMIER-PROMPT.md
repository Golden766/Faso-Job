# Premier prompt

Utilisez ce prompt pour démarrer l'agent IA :

```text
Vérifie d'abord que Python et Git sont installés sur la machine. Lis les consignes du projet, notamment AGENTS.md, puis guide la préparation de l'environnement Windows avant de créer l'application.

Travail en français simple. Utilise Python et Django comme framework principal. Privilégie les templates Django, les fichiers CSS, les vues Django et les modèles Django. Ne crée pas de API séparée ni de framework frontend sans justification claire et validation préalable.

Avant de coder, confirme la disponibilité de l'environnement virtuel Python, les dépendances nécessaires et l'organisation du projet. Ensuite, propose et applique la mise en place du projet Django en respectant les règles métier du projet : provenance des offres, vérification des sources, statut de publication et disponibilité restent distincts.
```

## Objectif de cette étape

- Vérifier l'environnement technique ;
- lire les instructions du projet ;
- préparer le contexte avant toute création d'application ;
- commencer le développement Django de manière structurée et contrôlée.
